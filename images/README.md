# Images Directory

## Required Images

Place the following images in this directory:

### 1. iptv-devices.png
- Dimensions: 800x600px or larger
- Content: Illustration showing IPTV on multiple devices (TV, phone, tablet, laptop)
- Format: PNG with transparency preferred
- Used in: About section

### 2. hero-background.jpg (optional)
- Dimensions: 1920x1080px
- Content: Abstract tech/streaming themed background
- Format: JPG
- Used in: Hero section background

## Image Resources

Free stock images for IPTV/streaming themes:
- Unsplash.com
- Pexels.com
- Freepik.com (free account)

## Optimization

Before uploading, optimize images:
- Use TinyPNG.com or similar
- Convert to WebP format for better performance
- Keep file sizes under 200KB when possible

## Alternative

If you don't have custom images, the theme will work without them. The CSS gradients and colors provide a complete visual experience.
